# 黑土粮仓 · 吉韵新程

> 吉林现代数字乡村振兴与生态农业 3D 展馆
> 长春市高校大学生网页设计作品 · 选题类别：乡村振兴 / 讲好中国故事

一个以**乡村振兴**为主题的数字展馆网站。它把吉林的黑土保育、稻作农时、智慧农机、生态文旅与地理标志物产，组织成一次可以拖拽、可以下潜、可以漫游的线上展览。

项目不依赖后端与数据库，所有几何、纹理、图版与文案都在本地构建，断网也能完整参观。

---

## 一、为什么做这个展馆

吉林处在世界三大黑土带之一，一厘米耕层需要数百年的枯荣与冻融。乡村振兴不只是产量数字，它同时是耕地怎么被保护、农时怎么被安排、装备怎么被改造、非遗怎么被延续、产出怎么被追溯。

展馆按「微观 → 工业 → 宏观 → 人文」的尺度递进编排：

| 主线 | 对应展陈 | 现实坐标 |
| --- | --- | --- |
| 黑土保育 | 3D 黑土地质标本馆、互动科普实验室、梨树模式 | 中科院东北地理所「黑土粮仓」科技会战、梨树长期定位试验田 |
| 智慧装备 | 3D 北斗农机解构馆、数智驾驶舱 | 长春国家农业高新技术产业示范区、一汽工业基因 |
| 稻作农时 | 一粒米的旅程、二十四节气农耕物候谱 | 松花江与饮马河灌区、九台现代农业核心园区 |
| 生态文旅 | 查干湖冬捕生态非遗馆 | 松原查干湖，国家级非物质文化遗产 |
| 产出与流通 | 吉林风物特产集市 | 地理标志物产、一袋一码溯源 |

## 三、快速开始

```bash
npm install
npm run dev       # 本地开发
npm run build     # 生产构建，输出到 dist/
npm run preview   # 预览构建产物
```

构建产物约 2.5 MB（含 10 张 SVG 图版）。首屏只加载主包约 233 KB（gzip 约 88 KB）、Vue runtime 62 KB、Pinia 与图标两个小 chunk，FCP 约 80 ms，不加载任何 Three.js 或 ECharts。Three.js（693 KB / gzip 175 KB）与按需注册后的 ECharts（576 KB / gzip 195 KB）都是异步 chunk，只在进入 3D 展厅与图表页时下载；`/exhibit-map` 是独立的 23 KB（gzip 7.7 KB）异步 chunk，首页沙盘还要等滚入视口才挂载。

## 四、技术栈

| 层 | 选型 |
| --- | --- |
| 框架 | Vue 3.5（Composition API / script setup）、Vue Router 4、Pinia 4 |
| 构建 | Vite 8、Tailwind CSS 4、PostCSS |
| 三维 | Three.js 0.187、自定义 IBL 画廊环境、GTAO、物理折射材质、程序化几何与 Canvas 纹理 |
| 动效 | GSAP 3 + ScrollTrigger、CSS 逐字入场、滚动视差、`prefers-reduced-motion` 降级 |
| 图表 | ECharts 6 |
| 图版 | `scripts/generate_art.py` 程序化生成的 10 张 SVG，统一色板、任意缩放不失真、无外部图片依赖 |

重新生成图版：`python scripts/generate_art.py`，输出在 `public/art/`。

## 五、设计语言

- **色板**：宣纸暖白 `#F7F4EE`、深松烟墨 `#1C1B18`、秋收琥珀金 `#C88A32`、长白山苔藓青 `#2E5A44`、长春工匠赤红 `#B83828`。
- **排版**：中文衬线大标题（含 Windows 中文回退字体栈）、等宽眉题与编号、导语 / 正文 / 图注四级层次，大标题用 `text-wrap: balance` 避免孤字。
- **材质**：双层 bezel 边框、实心色块 Bento、Z 轴层叠卡、胶片颗粒、柔光与斜切色块。九个展陈页各有一套由其主题决定的首屏骨架，不共用模板扉页。
- **可访问性**：键盘焦点环、跳到主内容链接、动效降级、图片 alt、WebGL 不可用时切换为静态展签。

## 六、数据口径

展馆内 8000+ 万亩、880 亿斤、93.5%、4.82%、±2.5 cm、180 天等数字，均为**教学演示用的量级与示意指标**，参照 2024–2026 年间公开统计公报、黑土地保护规划资料与农业技术通用参数整理，不对应某一年的精确统计值，不用于生产决策。逐条口径、性质与参照来源集中列在 `/about` 的「展陈数据口径与来源」区块。

三维模型为参数化概念复原，非实物扫描或量产型号工程图纸。

助农专题三页采用公开可查的现实主体与项目类型，不编人名、自述、覆盖户数与增收金额，成效只用定性描述。方位索引与 `/exhibit-map` 展览地图都是抽象策展示意，页面明确标注「策展动线示意，非行政区划地图」：不画省界县界、不使用经纬度、不接任何地图 SDK 或在线地图服务。认养地块、收益条形与凭证都是教学演示，不产生真实交易、不收集个人信息。

「最后一公里实验室」把 2025–2026 年公开讨论的痛点做成三个可交互实验。矛盾类型、时间区间与成本量级出自中央一号文件、经济参考报、新华社、人民日报、中国农网及黑土地保护相关研究，逐条列在 `/about` 附录 B。页面里的示意指数、地块编号与负担档位均为教学演示，不写人名，不把地方调研样本外推为全国均值。

认养一亩田页的口径说明区提供「教学演示 / 模拟真实数据」切换，用来演示接入业务系统后的认养档案字段与交互形态。切换后出现的认养人、地块编号、产量与凭证**全部为虚构演示值**，页面明确标注，不产生真实认养关系、不收集个人信息、不发生交易。

`public/art/` 下的 10 张 SVG 图版由 `python scripts/generate_art.py` 程序化生成。修改图版请改生成脚本后重跑，不要直接编辑 SVG 产物；全部图版只用抽象网格、色块与刻度表达策展顺序，不含经纬度与行政区划边界。

## 八、部署注意

- `vite.config.js` 未设置 `base`，部署到子路径时需要按需配置。
- `index.html` 里的 Open Graph 标签是静态兜底，抓取器不执行前端路由脚本。若要为不同子页生成独立分享卡片，需要预渲染或服务端注入。
- 分享卡片图片建议使用部署后的绝对地址替换 `og:image`。
