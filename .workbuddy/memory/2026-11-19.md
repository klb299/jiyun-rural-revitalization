## 16:35 绿底卡片发暗的真正根因：入场中间态（纠正上一轮误判）

- 用户再次截图问「为啥没变化」，截图里导航与页脚都是新名，证明不是缓存。
- 真正根因：首页绿底科普入口三张卡用 `Reveal` 默认淡入（opacity 0→1，0.45s，delay 90ms 递增）。滚动经过时正好在中间态，白字半透明叠深绿读成黑字。上一轮我等了 3.6s + 额外 900ms 才取色，躲开了中间态，误判成缓存。
- 修法：`Reveal.vue` 加 `variant="solid"`；`style.css` 加 `.reveal--solid { opacity:1 }`，只保留 16px 位移；首页该区块 4 个 Reveal 全改 solid。其它页不动。
- 验证：滚动后 **80ms** 抓拍，4 个 reveal 全部 `opacity:1`、三张卡文字完全清晰（`green-instant.png`）；build 零警告、`npm run audit` **12/12 全绿**、控制台 0。
- 文档 `PROJECT_HANDOVER.md` 修复三十七节、`VISUAL_HANDOFF.md` 第 24 节、`NEXT_PHASE.md` 最新状态、本日志。
- 经验：用户说「看不清」必须检查动画中间态；验证要复现用户动作（滚到即拍），不能等动画播完再取计算色。我这次误判了一轮，得记住。

## 21:15 Edge 黑字 Chrome 白字的真正根因

- 用户：同一个网址 Edge 是黑的、Chrome 是白的。这解释了前面几轮「改了没变化」。
- 根因：项目完全没声明 `color-scheme`，Edge 在系统深色主题下自动把网页文字反转，Chrome 默认不这么做。不是缓存、不是入场动画、不是具体文字类。
- 修复：`index.html` 加 `<meta name="color-scheme" content="light" />`，`style.css` 顶部加 `:root { color-scheme: light; }`。
- 验证：playwright 模拟 colorScheme dark / light 两种系统主题，根部 colorScheme 均锁定 light，绿底标题两种情况下都是 rgb(247,244,238)；build 零警告、`npm run audit` **12/12 全绿**。
- 文档 `PROJECT_HANDOVER.md` 修复三十八节、`VISUAL_HANDOFF.md` 第 25 节、`NEXT_PHASE.md`、本日志。
- 经验：跨浏览器表现不同 → 先查 color-scheme / 强制深色，不要改具体色值或加版本号。我前面误判了三轮。
