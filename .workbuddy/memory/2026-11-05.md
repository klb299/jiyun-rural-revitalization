## 阶段四：3D 展馆模型精度升级（19:22 用户回来要求「继续」）

**接手时的真实状态**：下午那一轮在 `textures.js` 里造好了六个高精度程序化几何工具，但**全部零引用**，场景里仍是圆柱+球体的早期低模。所以「继续」= 把零件装进场景，不是继续加新工具。

**装配**（只改 3D 渲染层，不碰页面/导航/样式/色板/后台）：
- `RuralSandbox3D.vue`：风机叶片换 `airfoilBladeGeometry(length, 0.66, 28, 44)`、金色前缘条 x=0.2；玉米换 `makeDetailedCornStalkGeometry`
- `scienceScenes.js`：稻株换 `makeDetailedRiceStalkGeometry`；团粒/结核换 `sculptedAggregateGeometry`；删掉不再用的 `mergeGeometries` import
- `SoilStrata3D.vue`：矿物团粒/钙质结核换 `sculptedAggregateGeometry`
- `SmartMachinery3D.vue`：`buildWheels` 新增 `coilSpringGeometry` 双簧减震悬挂

**踩的坑**：
1. `curvedLeafGeometry` 是单层曲面（无厚度），玉米材质必须 `side: THREE.DoubleSide`，否则背面叶片消失。稻株材质本来就是 DoubleSide。
2. 科普把株高从 0.44 放大到 0.95 后，茎粗/叶宽/谷粒仍是基准值，远景像一丛干草。给 `makeDetailedRiceStalkGeometry` 加 `widthScale` 参数（科普传 1.6），横向尺寸随株高同步放大，默认 1 向后兼容。
3. 弹簧初版埋在宽断面胎体里看不见，抬到 `springY = cfg.r * 0.94` 才从轮组顶部露出。

**验证**：`npm run build` 零 Error；13 条路由逐页 0 Error / 0 Warning；四个 3D 场景 + 爆炸分解 + 科普三实验切换 + 时间轴五阶段逐帧截图确认；移动端 390×844 零横向溢出。改动前六个源文件备份在 `.backup_3d_upgrade_20261105/`。

**经验（可复用）**：判断一个「继续」任务该做什么，先看有没有**已写好但零引用的导出**——那是上一轮被打断的位置，比重新设计新功能更接近用户意图。可用 node 脚本扫 `^export function` 再在所有业务文件里搜名字定位。

**文档**：`PROJECT_HANDOVER.md` 第十一节、`3D_HANDOFF.md` 几何工具速查与常见任务表已同步。

## 全站自查结论（21:06，仅诊断未改代码）

- P0 首屏性能：`HomeView.vue` 静态 import `RuralSandbox3D.vue`，且路由里 HomeView 也是静态 import，导致整个 Three.js 被打进 `dist/assets/index-*.js`（932K）。实测首页只请求 2 个 js，FCP 1552ms，一进首页立刻创建 1 个 WebGL 上下文（沙盘在首屏之外）。修法：首页沙盘改 `defineAsyncComponent` + IntersectionObserver 懒挂载，路由改动态 import。
- P0 视觉遗留：12 个视图里只有 Home / Dashboard / Science 用了 `bezel` + 手工非对称构图，其余 9 页仍是 `PageHero + SectionHead×5 + surface-ink` 同一套对称两栏骨架（AboutView、ChaganLakeView 截图确认），也就是用户之前抱怨「像 Claude、太朴素」的同款结构，阶段二只修了 3 页。
- P0 健壮性：`stage.js` 的 `new THREE.WebGLRenderer()` 无 try/catch、无 `webglcontextlost` 处理、无 WebGL 不支持时的静态图兜底，老设备或禁用硬件加速会白屏。
- P1：两个图表组件都 `import * as echarts`，chunk 1.1M，按需引入可砍约一半；README 仍是 Vite 模板；`HelloWorld.vue` 与 3 个 assets 遗留未删；无 404 路由（实测 `/no-such-page` 主区空白）、无 OG 分享卡、无 per-route description；无全局 `:focus-visible`（浏览器默认 auto 1px）；墨色 hero 上导语文字对比偏灰。
- P2：页面里 8000+ 万亩 / 880 亿斤 / 93.5% / 4.82% 等数字没有逐条口径与年份，只有 About 一句教学演示免责；后台密码明文 + localStorage 登录态，答辩要说明是演示门禁；3D 无滚动懒挂载，纹理全局缓存跨展厅常驻显存。
