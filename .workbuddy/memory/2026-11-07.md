## 第二十轮：自查后的工程精进

- 用户问「自查一下觉得哪里可以精进」。先写 `audit-a11y.js` 补探针盲区：768/1024/1280/1920×6 页零溢出、未命名控件 0、reduced-motion 47 元素全可见、5 条路由 meta 全对、数量口径一致、无调试残留。结论是短板不在视觉，在工程与键盘细节。用户勾选三项全部执行。
- **导航可访问性**：4 个分组按钮补 `aria-expanded/haspopup/controls`，header 加 `@keydown.esc`，容器加 `@focusout`，移动端按钮补 `aria-expanded`；面板 `v-if→v-show` 让 controls 的 id 常驻、避免断头 ARIA 引用。键盘实测 `false→Enter→true→Esc→false`，焦点移出也收起。
- **踩坑经验**：`@mouseenter` 先置位 + `@click` 再 toggle，导致 Playwright `click()`（会移动鼠标）表现为「点了反而关掉」，纯键盘 Enter 正常。**测这个导航必须用 `focus()+keyboard`，不能用 `click()`**。

- **SVG 降采样**：`contour step 8→14`、hero dots `260→160`、panorama dots `420→240`，**449KB→321KB（省 128KB / 28.6%）**，5 张等高线图版变化、其余 5 张字节不变，截图确认曲线平滑无锯齿。改的是 `scripts/generate_art.py`。
- **工程基建**：`git init` + `.gitignore` + 首次提交 `ab25358`（此前不是 git 仓库，第十九轮改动无快照）。忽略 dist/node_modules/.playwright-cli 与备份截图日志，**`.workbuddy/tools/` 和 `memory/` 必须提交**。`package.json` 加 `art` / `audit` / `snapshot`；`npm run audit` 实测 7/7 探针取到结果，`npm run snapshot` 实测 69 文件 / 1.4MB。
- **环境坑（重要）**：本环境 Node 被注入 `node-brokered-fs-shim`，凡用 `fs` 的 `.mjs` 静默退出 127（纯 console.log 的 mjs 正常），且无任何 stderr。排查靠 `NODE_DEBUG=module` 才看到 shim。**结论：这个环境里写 Node 工具脚本别依赖 `fs` 模块，改用 Python**，与既有 `generate_art.py` 一致。
